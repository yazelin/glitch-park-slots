# 格莉奇遊樂園・777 拉霸

一款可獨立開啟的 Three.js 角色拉霸遊戲。投入代幣時會看見硬幣落入投幣孔，再拉下機台把手讓三個轉輪依序停止；三格相同時會觸發 777 JACKPOT、掃過中獎線、灑下彩色碎光，並把角色加入本機收藏。

## 操作

- 手機與桌機：點擊機台投幣孔或畫面右下角按鈕，再點右側把手。
- 鍵盤：`C` 投幣、空白鍵拉下把手。
- 右上角可切換全部聲音，並查看中獎收藏。

機台會依投幣、拉桿、轉輪運轉、各輪停止與中獎播放不同音效；跑馬燈、機身震動和得獎燈光也會配合遊戲階段變化。

主機與後排機台的角色轉輪共用單一 Atlas，角色圖以圓形網格與透明遮罩裁切。後排六台同樣具有三格轉輪、777 燈牌、操作面板、出幣口與側邊拉桿，不會把一張角色圖直接當成整台機器。

## 本機執行

```bash
python3 -m http.server 4173
```

瀏覽 `http://127.0.0.1:4173/`。角色圖使用單一 Atlas，Three.js 也放在 repo 內，不依賴外部 CDN。

日後嵌入 Larch 時，頁面會自動顯示「離開」按鈕，並以 `postMessage` 交由外層播放遊樂園主題曲。
