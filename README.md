# 格莉奇遊樂園・777 拉霸

一款可獨立開啟的 Three.js 角色拉霸遊戲。投入代幣後拉下機台把手，三個轉輪會依序停止；三格相同時會觸發 777 JACKPOT，並把角色加入本機收藏。

## 操作

- 手機與桌機：點擊機台投幣孔或畫面右下角按鈕，再點右側把手。
- 鍵盤：`C` 投幣、空白鍵拉下把手。
- 右上角可切換全部聲音，並查看中獎收藏。

## 本機執行

```bash
python3 -m http.server 4173
```

瀏覽 `http://127.0.0.1:4173/`。角色圖使用單一 Atlas，Three.js 也放在 repo 內，不依賴外部 CDN。

日後嵌入 Larch 時，頁面會自動顯示「離開」按鈕，並以 `postMessage` 交由外層播放遊樂園主題曲。
